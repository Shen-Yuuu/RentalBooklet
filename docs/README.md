## 关键决策速览（2026-09 官方文档核实，v1.1 修订）

| 决策 | 结论 |
| --- | --- |
| PDF 生成 | `@kit.PDFKit` pdfService（API 12+，离线、可搜索）；PdfView 组件内嵌预览；仅中国大陆真机 → **不支持时明确提示（SnapshotRenderer 已裁剪）** |
| 拍照 | cameraPicker 系统选择器，**不申请相机权限**；相册导入 PhotoViewPicker 免媒体库权限 |
| OCR | Core Vision Kit `textRecognition` 端侧离线，结果必须用户确认 |
| 语音 | Core Speech Kit `speechRecognizer`（zh_CN、≤60s）+ 本地规则中性化，不上云 |
| 哈希 | `@kit.CoreFileKit` hash（SHA-256，文件级），冻结事务统一幂等计算 |
| 分享/导出 | Share Kit 系统分享面板（多文件记录）+ DocumentViewPicker（均免权限）；**不做 zip 打包（R5 消解）** |
| 卡片 | Form Kit 2x2 进度卡，主动刷新，postCardAction 深链 |
| 碰一碰 | OneHop 不对普通开发者开放，不单独集成 |
| 权限 | 仅 MICROPHONE + LOCATION（默认关）；**INTERNET 已移除（逆地理推迟 v1.1）** |
