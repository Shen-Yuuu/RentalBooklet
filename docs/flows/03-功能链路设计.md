## L1 选择场景

**目标**：无注册、两步内进入检查准备。**前置**：冷启动/首页。
**数据写入**：无（选择结果经路由参数传递）。

```mermaid
sequenceDiagram
    participant U as 用户
    participant Home as 首页
    participant Scene as sceneSelect
    U->>Home: 点击「开始检查」FAB
    Home->>Scene: push sceneSelect {houseId?}
    Scene-->>U: 6 张场景卡片（名称+说明+预计用时）
    U->>Scene: 点选「入住验房」
    Scene->>Scene: houseId 为空 → houseEdit；否则直接预览模板摘要
```

- **异常分支**：无。
- **验收**：不注册可用；从首页到模板摘要 ≤ 2 步。

## L2 建立房屋档案

**目标**：最少必填建立档案，隐私默认安全。
**数据写入**：`house` 表 1 行。

```mermaid
sequenceDiagram
    participant U as 用户
    participant HE as houseEdit
    participant HR as HouseRepo
    U->>HE: 填写房屋简称(必填)·日期(默认今天)·户型(选择器)
    U->>HE: 可选：称呼/手机/租约止期/完整地址/记录位置(默认关)
    U->>HE: 保存
    HE->>HR: insert house
    HR-->>HE: houseId
    HE->>HE: push sceneSelect?（新档案）或返回
```

- **规则**：简称外显；完整地址存 `full_address` 且 UI 一律折叠（点击展开显示）；`record_location=false` 时不请求定位权限。
- **异常分支**：简称空 → 保存按钮禁用；手机号非 11 位 → 行内提示不阻塞。
- **验收**：仅填简称即可建档；首页卡片只见简称。

## L3 检查路线生成（模板实例化）

**目标**：按场景模板 + 户型生成"入户门→…→钥匙"的检查会话。
**数据写入**：`inspection`（DRAFT）+ `room` 若干 + `check_item` 若干（均来自模板）。

```mermaid
flowchart TD
    S[确认场景+houseId] --> T[TemplateEngine.load sceneKey]
    T --> M{户型裁剪}
    M -- 无阳台/无次卧 --> R1[移除对应房间]
    M -- 复式 --> R2[追加次卫/书房]
    R1 --> C[创建 inspection DRAFT started_at=now]
    R2 --> C
    C --> W1[写入 room 列表·按路线顺序 sort]
    W1 --> W2[每房间写入 check_item·含 required/photoGuide]
    W2 --> H[跳转 inspection 检查执行页]
```

- **规则**：房间 `sort` 即检查路线；`template_key` 全链路稳定（前后对比对齐键）；退出 App 后 DRAFT 保留。
- **异常分支**：模板 JSON 缺失/损坏 → 首启解包校验失败即提示重装（不静默空模板）。
- **验收**：入住模板生成 9 房间 ~50 检查项；杀进程重进回到同一 inspection。

## L4 逐项拍照与记录（核心高频链路）

**目标**：照片与检查项强绑定、零等待、可中断。
**数据写入**：`photo` 行 + 沙箱图片文件；`check_item.status/note` 即时更新。

```mermaid
sequenceDiagram
    participant U as 用户
    participant IE as inspection 执行页
    participant SE as itemEdit 半模态
    participant CP as cameraPicker(系统)
    participant PM as PhotoPipeline(TaskPool)
    participant DB as PhotoRepo/ItemRepo
    U->>IE: 点检查项 → 打开半模态
    U->>SE: 拍全景照
    SE->>CP: pick(Photo)
    CP-->>SE: resultUri
    SE->>PM: 入库管线(copy→转码JPEG→原图+缩略→亮度/模糊启发式)
    PM-->>DB: insert photo(CAPTURED, 元数据) (异步, 缩略图先返回)
    SE-->>U: 缩略图角标立即可见
    U->>SE: 或「从相册导入」→ PhotoViewPicker → 同管线(source=IMPORTED)
    U->>SE: 三态标记 正常/存在问题/不适用 + 备注/语音
    SE->>DB: update check_item(即时提交)
    SE-->>IE: 返回列表，自动定位下一 PENDING 项
```

- **规则**：IMPORTED 照片全链路（列表角标 + PDF）标注"从相册导入"；质量提示（过暗/缺全景/只有文字）只在 UI 提示不拦截。
- **异常分支**：拍摄取消 → 无写入；存储 <200MB → 拍前提示；管线失败 → 项仍可标状态，照片列表显示"重试"。
- **验收**：快门→缩略图 ≤1s；连续拍 10 张无卡顿；杀进程不丢已拍照片与状态。

## L5 表数 OCR 链路

**目标**：水电燃气表读数自动化识别 + 强制人工确认。
**数据写入**：`meter_reading`（含 `confirmed` 门闩）+ `photo(kind=METER)`。

```mermaid
sequenceDiagram
    participant U as 用户
    participant MO as meterOcr 页
    participant OS as OcrService(CoreVision)
    participant DB as MeterRepo
    U->>MO: 拍摄表盘(取景引导框: 表盘入框+读数窗提示)
    MO->>OS: recognizeText(pixelMap)
    OS-->>MO: 文本块[] + 坐标
    MO-->>U: 候选读数高亮(按坐标框选数字块)
    alt 识别可信
        U->>MO: 确认候选值(或手动修正)
    else 低置信/失败
        MO-->>U: 引导手动输入(不阻塞)
    end
    U->>MO: 保存
    MO->>DB: insert meter_reading(ocr_raw, ocr_conf, value, confirmed=1)
    Note over DB: confirmed=0 的记录永不进入报告
```

- **异常分支**：OCR 失败 → 手动输入；表具不存在 → `na_flag=1`；重复拍 → 覆盖旧 photo（保留历史可删）。
- **验收**：常见机械表/数显电表在光线正常下命中候选；确认步骤不可跳过。

## L6 语音备注与中性化链路

**目标**：语音省打字；AI 只整理语言不改事实。
**数据写入**：`check_item.note_raw / note_suggestion / note_final`。

```mermaid
sequenceDiagram
    participant U as 用户
    participant SE as itemEdit 半模态
    participant SR as SpeechService(CoreSpeech)
    participant TR as TextRefiner(本地规则)
    U->>SE: 按住麦克风说话(≤60s)
    SE->>SR: startListening(zh_CN)
    SR-->>SE: 转写文本
    SE->>TR: refine(text)
    TR-->>SE: 建议文本 + 规则明细[{before,after,ruleName}]
    SE-->>U: 原文/建议 对照展示
    U->>SE: 采纳建议 / 保留原文 / 手改
    SE->>SE: 写 note_final(即时落库)
```

- **规则**：无权限 → 引导开权限或直接手输；60s 上限到点自动结束；每条建议可独立采纳。
- **异常分支**：识别失败/静音 → 提示重试或手输；真机不支持 → 按钮隐藏。
- **验收**：示例句"主卧窗户左下角有一条十厘米左右的裂缝"产出建议"主卧窗户左下角可见线状裂纹，长度约 10 厘米"；原文永不被覆盖。

## L7 完整性检查链路

**目标**：进入冻结前给出遗漏清单与完整度。
**数据写入**：无（纯计算 + waiver 标记写 `check_item.waiver`）。

```mermaid
flowchart TD
    R[review 页进入] --> E[CompletenessEngine.check]
    E --> O1[必须项: R1房间已处理·R2三表·R3钥匙门禁·R4问题项有照片或备注]
    E --> O2[建议项: R5全景照·R6入户门近照·R7中性化]
    O1 --> P{必须项全部通过?}
    P -- 否 --> J[遗漏清单·逐条跳转] --> U2[处理后重查]
    P -- 是 --> P2{建议项?}
    P2 -- 有缺 --> W[展示可继续] --> G[去确认冻结]
    P2 -- 无缺 --> G
    P -- 强制继续 --> W2[二次确认弹窗: 遗漏将记入报告完整度快照] --> G
```

- **措辞**：标题"记录完整度"；副文案"反映本次记录的齐全程度，不代表证据效力"。
- **验收**：千项以内计算 ≤200ms；每条遗漏可一键跳转对应项/房间。

## L8 确认、签名与冻结链路（一致性核心）

**目标**：生成不可变记录 + 校验清单。
**数据写入**：`signature`、`inspection(status/report_no/frozen_at/complete_*)`、`photo.sha256`、`manifest`。

```mermaid
sequenceDiagram
    participant U as 用户
    participant CS as confirmSign 页
    participant FS as InspectionService
    participant TP as TaskPool(Hash)
    participant MB as ManifestBuilder
    participant RR as ReportRenderer
    U->>CS: 核对摘要(时间/参与人/三表/钥匙门禁/问题数)
    opt 参与人确认(v1.1: 文本姓名确认, 签名画板推迟 v1.1+)
        U->>CS: 填写房东/租客姓名 → participants JSON 落库
    end
    U->>CS: 点击「冻结本次记录」
    CS->>FS: freeze(inspectionId)
    FS->>FS: reportNo=RB-YYYYMMDD-xxxx
    FS->>TP: 并行 hash 待冻结文件(幂等, 已算跳过)
    TP-->>FS: photo.sha256 / signature.sha256 回填
    FS->>MB: build manifest(表+manifest.json 落盘)
    FS->>FS: 事务: UPDATE inspection SET status=FROZEN, frozen_at, complete_*
    FS-->>CS: 冻结完成(界面转只读)
    FS->>RR: 异步 render(inspectionId)
    RR-->>FS: report/{reportNo}.pdf + pdf sha256 登记 → 卡片刷新
```

- **规则**：冻结后 UI 全只读；再次修改 → 创建修订版本（复制记录 `revision_no+1`，`parent_revision_id` 链接，老记录原样保留）。
- **异常分支**：hash 中断 → 重跑幂等；PDF 失败 → 冻结态保留，报告页"重新生成"。
- **验收**：冻结后再无任何写路径触碰冻结记录；断电/杀进程后重进状态一致；manifest 重算 hash 全部匹配。

## L9 PDF 与交付包链路

**目标**：三种产物可读、可分享、可归档。
**数据写入**：报告文件 + `pdf sha256` 登记。

```mermaid
flowchart TD
    F[冻结完成] --> RC[ReportComposer 组装 PdfDocModel]
    RC --> P1[封面: 编号/房屋/时间/参与人]
    RC --> P2[交接数据: 三表读数+照片缩略·钥匙门禁·补充说明]
    RC --> P3[逐房间页: 全景照+检查项表(状态/描述/细节照)]
    RC --> P4[问题汇总表]
    RC --> P5[确认信息页: 参与人姓名+确认时间]
    RC --> P6[校验信息页: manifest 摘要+免责文案]
    P1 & P2 & P3 & P4 & P5 & P6 --> RD[PdfKitRenderer 渲染]
    RD --> PV[reportPreview: PdfView 组件内嵌预览]
    PV --> EX[systemShare 多文件分享 PDF+manifest+原始照片 / DocumentViewPicker 逐文件导出]
```

- **PDF 规则**：内嵌图片统一用缩略 JPEG（≤1280px，控制体积）；原图以"原图编号 ↔ 文件名"映射表出现在校验页；PDF 自身 hash 生成后登记 `inspection.pdf_sha256`，在归档详情展示。
- **异常分支**：pdfService 不可用（非大陆设备/模拟器）→ 明确提示"当前设备不支持生成 PDF"（v1.1：SnapshotRenderer 已裁剪）；分享面板多文件直达，不做 zip。
- **验收**：接收方无 App 可读；30 页 PDF ≤20s；分享面板出现微信/邮件/华为分享。

## L10 归档复查与修订链路

**目标**：几个月后验证"文件没变过"，或安全地修改。

```mermaid
flowchart TD
    A[archiveDetail] --> V[点击「校验复查」]
    V --> H[TaskPool 对 manifest.files 逐一 hash 重算]
    H --> C{与登记值一致?}
    C -- 全部一致 --> OK[绿标: 文件未发生变化]
    C -- 不一致 --> BAD[红标: 列出差异文件+警告文案]
    A --> M[创建修订版本]
    M --> CP[复制 inspection/room/check_item 引用结构·revision_no+1]
    CP --> DR[新 DRAFT 进入检查执行页]
    DR --> FZ[重新走 L7→L8 冻结·生成新 manifest]
```

- **规则**：复查只对比 manifest 内文件；警告文案明确"检测到文件变化，不代表必然篡改（也可能是正常转存失败），请人工核对"。
- **验收**：改动任一原始文件字节后复查可检出。

## L11 退租前后对比链路

**目标**：复用入住结构，逐项对照，用户确认变化。

```mermaid
sequenceDiagram
    participant U as 用户
    participant HD as houseDetail/sceneSelect
    participant CP as compare 页
    participant DB as InspectionRepo
    U->>HD: 退租检查创建 → 选择基线=入住报告(建议默认)
    HD->>DB: inspection.baseline_inspection_id=入住id
    Note over DB: L3 实例化时按 template_key 对齐复用房间与项目
    U->>CP: 打开对比(退租录入过程中/完成后)
    CP-->>U: 逐项: 入住照片+描述 ↔ 退租照片+描述
    U->>CP: 逐项确认: 无变化/有变化/待确认
    CP->>DB: 写入确认结果(退租记录)
    CP-->>U: 汇总: 有变化项清单 → 可进退租 PDF
```

- **规则**：`template_key` 对不上的项目标"新增项"；App 只呈现不归因（不出现"由租客造成"类文案）；对比结论表进入退租 PDF 汇总。
- **验收**：同结构记录自动对齐率 100%；示例（客厅墙面无变化/冰箱门凹陷有变化）可复现。

## L12 服务卡片链路

**目标**：桌面直看"入住检查完成 18/24 项"，点击续作。

```mermaid
sequenceDiagram
    participant IP as 检查执行页/冻结流程
    participant WS as WidgetService
    participant FP as formProvider
    participant C as 桌面卡片(2x2)
    IP->>WS: 进度变化/冻结完成
    WS->>FP: updateForm(卡片数据: 房屋名·场景·x/y·状态)
    FP-->>C: 刷新
    U->>C: 点击卡片
    C->>IP: postCardAction(router) → 深链 push inspection{id}
```

- **规则**：卡片只展示"进行中或最近冻结"的一条检查；数据变化主动刷新（不用 30 分钟定时）；多卡片绑定靠 preferences 记录 formId↔inspectionId。
- **验收**：录入一项后回桌面 3 秒内数字更新；点击直达对应检查页。

## 异常分支总表

| 链路 | 异常 | 处理 | 用户可见反馈 |
| --- | --- | --- | --- |
| L4 | 拍摄取消 | 无写入 | 返回原界面 |
| L4 | 存储不足 | 拍前拦截 | "剩余空间不足，请清理草稿" |
| L4 | 转码失败 | 状态可标、照片重试 | 缩略位显示重试按钮 |
| L5 | OCR 失败/低置信 | 手动输入兜底 | "未能识别，请手动输入读数" |
| L6 | 麦克风权限拒绝 | 引导设置页 | 说明用途文案 + 跳转 |
| L6 | 识别失败 | 手输 | "没听清，试试再说或直接输入" |
| L8 | hash/PDF 中断 | 幂等重跑 | "生成中断，点击重试" |
| L9 | pdfService 不可用 | 明确提示不支持生成 | "当前设备不支持生成 PDF" |
| L9 | 非大陆设备 | 真机提示（无降级渲染器） | 报告页脚注说明 |
| L10 | 校验不一致 | 红标+人工核对指引 | 不做"篡改"定性表述 |
| 全局 | 模板缺失 | 重装提示 | 启动页一次性错误卡 |
